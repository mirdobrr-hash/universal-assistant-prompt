# Contributing to TaskClear Prompt

Русский и English welcome. Small, specific improvements and reproducible observations are more useful than general claims that the prompt is better.

## Suggest a change / Предложить изменение

1. Identify the affected file and the concrete problem.
2. Include proposed wording and explain the expected difference.
3. Preserve existing requirements or explicitly identify any trade-off.
4. Note whether the corresponding translation or short version needs an update.
5. State whether the suggestion has been tested. Do not invent measurements.

## Report an experiment / Сообщить о проверке

Use the report template in [EXAMPLES.md](EXAMPLES.md). Include a prompt commit, model/version, date, available settings and tools, exact anonymized inputs, outputs with and without the prompt, preselected scoring criteria and all attempts used in the comparison.

Label anecdotal observations as anecdotes. Do not infer support for every model from a single run. Remove credentials and personal information before submission.

## Scope

Relevant contributions include clearer instructions, translations, reproducible task examples, accessibility improvements and honest evidence. Advertisements, fabricated endorsements and unrelated promotional links do not belong in project issues.

The repository currently has no selected license. Do not introduce third-party material whose redistribution terms are unknown. Contribution and licensing terms should be resolved with the maintainer before incorporating externally owned material.
